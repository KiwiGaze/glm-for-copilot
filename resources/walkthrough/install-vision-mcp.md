GLM Vision is an optional local MCP server (the official [`@z_ai/mcp-server`](https://docs.z.ai/devpack/mcp/vision-mcp-server)) that gives Copilot Chat agent mode GLM-4.6V image understanding: UI-to-code, OCR, error-screenshot diagnosis, diagram and chart analysis, and more.

It runs on your own machine via `npx` (Node.js 18+, 22+ recommended) and uses your stored GLM API key — nothing else to configure.

Once installed, the server starts automatically when you send a chat message. You can manage it any time from `MCP: List Servers` in the Command Palette, and remove it with `GLM: Uninstall GLM Vision MCP Server`.
