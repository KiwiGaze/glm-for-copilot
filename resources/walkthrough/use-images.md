Attach or paste PNG and JPEG images directly in Copilot Chat.

GLM-5.3-Flash and FlashX receive images directly. For text-only models, the extension asks Flash to describe the images, then passes the description to the selected model as untrusted visual data. Both requests use the same API endpoint and key. Custom endpoints must provide a compatible `glm-5.3-flash` model.

[Edit the Flash image analysis prompt](command:glm-copilot.openVisionPromptSettings)
