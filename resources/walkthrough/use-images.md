Attach or paste PNG and JPEG images directly in Copilot Chat.

GLM-5.3-Flash receives images natively. When another GLM model is selected, the extension first asks GLM-5.3-Flash to describe the images, then gives that untrusted visual context to the selected model. Both requests use the same API endpoint and key; custom endpoints must provide a compatible `glm-5.3-flash` model.

[Edit the Flash image analysis prompt](command:glm-copilot.openVisionPromptSettings)
